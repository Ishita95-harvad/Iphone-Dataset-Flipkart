# 📱 iPhone Dataset - Flipkart

Welcome to the **iPhone Dataset - Flipkart** repository! This dataset compiles structured information about various iPhone models, including their specifications, pricing, and user ratings from Flipkart.

## 📌 Dataset Overview
- 📦 **Model Details:** Includes different iPhone versions, storage capacities, and colors  
- 💰 **Pricing Trends:** Tracks historical and current Flipkart prices  
- ⭐ **User Ratings & Reviews:** Aggregated consumer feedback and satisfaction scores  
- 🔍 **Availability Status:** Data on stock availability and seller information  

## 📂 Data Format
The dataset is structured in CSV format with key attributes:
- `Model Name` – iPhone version (e.g., iPhone 12, iPhone 13 Pro Max)  
- `Storage Variant` – Available storage configurations (64GB, 128GB, etc.)  
- `Color` – Listed color options  
- `Flipkart Price (INR)` – Current and past pricing trends  
- `User Rating` – Average rating from Flipkart reviews  
- `Stock Availability` – Whether the model is currently available
